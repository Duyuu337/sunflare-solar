# Sunflare Solar · 物品与方块功能详解

> 适用版本：1.21.1 + NeoForge 21.1.x
> 一切能量以 **FE** 收发，AE2 / 通用机械通过各自的转换设备取用。

---

## 一、太阳能板 I–VIII

### 基本属性

| 档位 | 名称 | 额定输出 (FE/t) | 内部缓冲 (FE) | 最大推送 (FE/t) |
|---|---|---|---|---|
| I | 微光板 | 32 | 128,000 | 256 |
| II | 集光板 | 128 | 512,000 | 1,024 |
| III | 聚能板 | 512 | 2,048,000 | 4,096 |
| IV | 晶格板 | 2,048 | 8,192,000 | 16,384 |
| V | 棱镜板 | 8,192 | 32,768,000 | 65,536 |
| VI | 日冕板 | 32,768 | 131,072,000 | 262,144 |
| VII | 恒星板 | 131,072 | 524,288,000 | 1,048,576 |
| VIII | 耀斑板 | 1,048,576 | 1,000,000,000（封顶） | 8,388,608 |

**缓冲容量公式**

```
缓冲 = 额定输出 × 4000，再与 1,000,000,000 取小
```

- I–VII 档都没有触到上限，严格按 ×4 递增（`512 × 4000 = 2,048,000`，`131,072 × 4000 = 524,288,000`）
- 只有 VIII 档算出来是 `1,048,576 × 4000 = 4,194,304,000`，超过 10 亿，被截断成 `1,000,000,000`
- VIII 档满发时约 **954 秒**（≈16 分钟）充满缓冲，此后靠推送维持收支
- 薄板厚度 **3/16 格**，可以贴着地面、墙面铺，不阻挡玩家通行。
- 每块板只往**六个相邻方向**推电，不主动拉取。

### 发电曲线

```
实际输出 = 额定 × 日照曲线 × 光照系数 × 天气系数 × 输出倍率
```

| 因子 | 规则 |
|---|---|
| 日照曲线 | `sin(π × 时间 / 12000)`，正午最强，日出日落为 0 |
| 光照系数 | 上方天空光照 / 15，被遮挡按比例衰减 |
| 天气 | 晴天 1.0，下雨 0.5，雷暴 0.25 |
| 输出倍率 | 默认 1.0，由**通量调控器**动态调整 |

放在没有天空光的地方（下界、末地）不发电。

### GUI（右键打开）

显示四行：缓冲 / 额定 / 当前输出 / 换算（AE/t 与 J/t），右上角有状态灯和关闭按钮。

- 状态灯绿色 = 正在发电
- 顶部纹理在发电时才播放流光动画，停机自动静止

### 换算参考

| 目标 | 比例 | 说明 |
|---|---|---|
| AE2 | **2 FE = 1 AE** | 需要 Energy Acceptor 接入 ME 网络 |
| 通用机械 | **0.4 FE = 1 J** | 直接接受 FE，无需转换器 |

## 二、光能核心 I–VIII

制作面板的**强制前置**，且逐级套娃：核心 N 需要核心 N−1。

| 核心 | 关键材料 |
|---|---|
| I | 铁锭 + 红石 |
| II | 金锭 + 核心 I |
| III | 钻石 + 核心 II |
| IV | 紫水晶碎片 + 核心 III |
| V | 下界合金锭 + 核心 IV |
| VI | 下界合金锭 + 核心 V |
| VII | 下界合金块 + 核心 VI |
| VIII | 下界之星 + 核心 VII |

面板配方 = 四角框架材料 + 四边玻璃 + 中心对应核心。

**耀斑板（VIII）** 是唯一的后期门槛：

```
下界合金块   末影之眼   下界合金块
末影之眼     核心 VIII  末影之眼
下界合金块   末影之眼   下界合金块
```

## 三、通量调控器 · Flux Governor

### 作用

解决后期"电满溢出"——自动压低面板输出，避免无意义的能量堆积。

### 工作方式

每 20 tick（默认）扫描一次半径内的耀阳板：

```
平均缓冲 > 95%  → 输出倍率降到 0.5
连续 3 次仍满   → 降到 0.0（完全停发）
平均缓冲 < 80%  → 每次恢复 0.25，直到 1.0
```

- 倍率写进面板 NBT，重载后保留
- 只影响**已经摆出来的**面板，不改 Tier 上限和配方
- 扫描半径默认 8 格

### 附带的总线调度

同一轮扫描里还会检查**优先级总线节点**的总电量：

```
< 20% → 断一条最低优先级的节点
> 40% → 恢复一条最高优先级的节点
```

### GUI

显示受控面板数、平均缓冲百分比、当前输出档位、已断开的总线数。

### 配置

```toml
[fluxGovernor]
radius = 8
intervalTicks = 20
highBuffer = 0.95
lowBuffer = 0.8
```

## 四、优先级总线节点 · Priority Bus Node

### 作用

带缓冲的 FE 中转站，可在电量紧张时被调控器按优先级切断，保住关键负载。

### 属性

| 项 | 值 |
|---|---|
| 缓冲 | 200,000 FE |
| 吞吐 | 20,000 FE/t |
| 优先级 | 1（最低）~ 5（最高） |

### 三种状态

| 状态 | 含义 |
|---|---|
| 供能中 | 正常收发 |
| 已降载 | 被调控器断开，不接收也不输出 |
| 已强制断开 | 玩家手动关闭 |

### GUI（右键）

- `−` / `+` 调优先级（1–5）
- 底部按钮切换强制通断
- 缓冲条显示当前电量

### 配置

```toml
[priorityBus]
lowNetwork = 0.2
highNetwork = 0.4
```

## 六、亚空间中继信标 · Subspace Relay Beacon

### 作用

随身充能器：把附近太阳能板的电抽到自己身上，再给背包里的能量物品充电。

### 两种工作模式

| 模式 | 条件 | 抽电范围 |
|---|---|---|
| 本地 | 没装备耦合卡 | 半径 16 格内的耀阳板 |
| 跨维度 | **耦合卡装备在饰品栏** | 卡片绑定的那一台面板，可跨维度 |

### 充能流程（每 20 tick 一次）

1. 从面板抽 FE 进信标缓冲（上限 400,000 FE）
2. 扣 10 FE 维护费，没电就停
3. 把缓冲的能量充给物品，**效率 90%**（10% 在传输中损耗，不会凭空生成）

充能顺序：**主手 → 副手 → 护甲 → 其余背包**。

### 双生效路径

- 放在**背包/快捷栏**：由玩家 tick 驱动
- 装备在 **Curios 饰品栏**：由 `curioTick` 驱动

两者互斥——同时存在时**优先使用饰品栏里的那个**，不会重复扣电。

未安装 Curios 时自动退化为纯背包模式，不报错。

### 右键

空手右键显示当前缓冲（`中继缓冲：xx / 400 kFE`）。

### 配置

```toml
[subspaceRelay]
radius = 16
capacity = 400000
transferPerTick = 2000
efficiency = 0.9
upkeepPerCycle = 10
```

## 七、超立方耦合卡 · Tesseract Coupling Card

### 作用

把某台耀阳板"登记"成信标的专属电源，突破 16 格限制并允许跨维度。

### 使用

| 操作 | 结果 |
|---|---|
| **Shift + 右键**耀阳板 | 绑定（记录维度、坐标、所有者） |
| **Shift + 右键**同一块板 | 解绑 |
| 普通右键面板 | 打开面板 GUI（不会绑定） |

### 生效条件

1. 卡片必须**装备在饰品栏**（护符 / 背饰槽），背包里放着不生效
2. 目标面板所在区块**已加载**
3. 目标面板还有电
4. 信标缓冲没满

### 失效情况

- 源面板被拆 → 抽取返回 0，信标自动退回本地模式
- 源区块未加载 → 不抽电（不会强加载）

## 八、超立方锚定节点 · Tesseract Anchor Node

### 作用

强制加载所在区块并保持运转，让**远端的面板继续发电**，供末地/其他维度的玩家使用。

### 规则

- 放置即加载所在区块（ticking 状态）
- 拆除即释放
- 每个维度**最多 3 个**（可配置），超过时无法放置并提示
- 不产电、不传能，只负责区块票据

### 配置

```toml
[tesseractAnchor]
maxChunks = 3
```

## 九、典型搭建流程

### 中期：本地充能

1. 摆几块太阳能板，接一根线到一个储电方块
2. 带上**中继信标**在附近活动
3. 背包里的电池、工具会自动回电

### 后期：跨维度供电

1. 主世界建好太阳能阵列
2. 在阵列旁边放**锚定节点**（保证区块持续加载）
3. 手持**耦合卡** Shift 右键那台面板完成绑定
4. 把耦合卡**装备到饰品栏**
5. 带上**中继信标**去末地，物品开始回电

### 满电管理

1. 在阵列中央放**通量调控器**
2. 关键产线接**优先级 5** 的总线节点，次要设备接 **1–2**
3. 电量吃紧时，调控器会先断开低优先级节点

## 十、常见问题

**Q：为什么面板不发电？**
A：检查上方是否有方块遮挡、是否在下雨、是否位于无天空光的维度。

**Q：信标不充电？**
A：确认缓冲没满、维护费扣得起、附近有已加载的耀阳板；跨维度模式还要确认卡片在饰品栏、源区块已加载。

**Q：耦合卡装不进饰品栏？**
A：需要 Curios 模组，且卡片被加入 `curios:charm` / `curios:back` 标签。

**Q：调控器把电压到 0 了怎么恢复？**
A：等缓冲降到 80% 以下会自动逐级恢复；也可以临时拆除调控器。

**Q：AE2 里看不到电？**
A：需要 Energy Acceptor 把 FE 转成 AE，比例 2:1。
