# 耀阳光能板（Sunflare Solar）· 完整指南

> 一个为 **Minecraft 1.21.1 + NeoForge** 制作的太阳能发电模组。
> 底层模组 ID：`sunflare`　｜　许可证：MIT　｜　前置：NeoForge 21.1.x
> Curios 为**可选**依赖，不装也能正常运行。

---

## 模组简介

耀阳光能板提供一条从「几块铁」到「一颗恒星」的完整发电科技线：

- **8 级超薄太阳能板**，从 32 FE/t 一路做到 1,048,576 FE/t
- **光能核心**逐级套娃，杜绝跳级逃课
- **FE 单一能量出口**，AE2 与通用机械都能直接取用
- **通量调控器 + 优先级总线节点**，解决后期溢出与保核心产线
- **亚空间中继系统**，让你在末地也能给背包充电
- **8 个成就**，含 3 个隐藏整活成就

所有方块都只暴露 NeoForge 的 `IEnergyStorage` 能力，**不硬编码任何 AE2 / 通用机械的类**，因此不装这两个模组也完全不影响运行。

## 一、太阳能板

### 数值总表

| 档位 | 名称 | 额定输出 | 内部缓冲 | 单 tick 最大推送 |
|---|---|---|---|---|
| I | 微光板 | 32 FE/t | 128,000 FE | 256 FE/t |
| II | 集光板 | 128 FE/t | 512,000 FE | 1,024 FE/t |
| III | 聚能板 | 512 FE/t | 2,048,000 FE | 4,096 FE/t |
| IV | 晶格板 | 2,048 FE/t | 8,192,000 FE | 16,384 FE/t |
| V | 棱镜板 | 8,192 FE/t | 32,768,000 FE | 65,536 FE/t |
| VI | 日冕板 | 32,768 FE/t | 131,072,000 FE | 262,144 FE/t |
| VII | 恒星板 | 131,072 FE/t | 524,288,000 FE | 1,048,576 FE/t |
| VIII | 耀斑板 | 1,048,576 FE/t | 1,000,000,000 FE（封顶） | 8,388,608 FE/t |

**缓冲容量算法**

```
缓冲 = 额定输出 × 4000，再与 1,000,000,000 取小
```

- I–VII 档都未触顶，严格按 ×4 递增
- 只有 VIII 档理论值为 `1,048,576 × 4000 = 4,194,304,000`，被截断为 10 亿
- VIII 满发时约 **954 秒**充满

### 发电公式

```
实际输出 = 额定 × 日照曲线 × 天空光照系数 × 天气系数 × 输出倍率
```

| 因子 | 取值 |
|---|---|
| 日照曲线 | `sin(π × 当日时间 / 12000)`，正午 1.0，日出日落 0 |
| 天空光照系数 | `上方天空光照 / 15`，被遮挡按比例衰减 |
| 天气系数 | 晴 1.0，雨 0.5，雷暴 0.25 |
| 输出倍率 | 默认 1.0，由通量调控器写入 |

- 无天空光的维度（下界、末地）**不发电**
- 每块板只向六个相邻方向推送，不主动抽拉

> **接线方式**
> 面板没有"输出面"的概念，会把电推给**任意相邻**的方块。
> 接入电网时，把线缆 / 管道 / 储电方块**贴着面板放**；隔一格空气是传不过去的。

### 物理特性

- 厚度 **3/16 格**，可贴地、贴墙、贴天花板
- 不阻挡玩家移动
- 发电时顶面播放流光动画，停机自动切静态帧

### 交互

右键打开状态面板，显示：缓冲 / 额定 / 当前输出 / 能量换算（AE/t 与 J/t）。

### 能量换算

| 目标 | 比例 | 说明 |
|---|---|---|
| AE2 | **2 FE = 1 AE** | 需 Energy Acceptor 接入 ME 网络 |
| 通用机械 | **0.4 FE = 1 J** | 直接接受 FE，无需转换 |

## 二、光能核心

八级核心，**逐级套娃**：核心 N 必须使用核心 N−1 合成，无法跳级。

| 核心 | 关键材料 |
|---|---|
| I | 铁锭 + 红石 |
| II | 金锭 + 核心 I |
| III | 钻石 + 核心 II |
| IV | 紫水晶碎片 + 核心 III |
| V | 下界合金锭 + 核心 IV |
| VI | 下界合金锭 + 核心 V |
| VII | 下界合金块 + 核心 VI |
| VIII | 下界之星 + 核心 VII |

面板配方 = 四角框架 + 四边玻璃 + 中心对应核心。

**耀斑板（VIII）** 为后期门槛：

```
下界合金块   末影之眼    下界合金块
末影之眼     核心 VIII   末影之眼
下界合金块   末影之眼    下界合金块
```

## 三、通量调控器

### 作用

后期面板产量远超消耗时，自动压低输出，避免无意义的溢出。

> **接线方式**
> 调控器**不需要接线**，它不传输任何能量，只负责"扫描 + 写倍率"。
> 放在阵列附近即可；离得太远会扫不到面板（半径见下方配置）。

### 判定逻辑

每 20 tick 扫描一次半径内的耀阳板：

```
平均缓冲 > 95%   → 输出倍率 0.5
连续 3 次仍满    → 输出倍率 0.0
平均缓冲 < 80%   → 每次恢复 0.25，直到 1.0
```

- 倍率写入面板 NBT，重载后保留
- 只影响已放置的面板，不改 Tier 上限与配方
- 同时负责调度优先级总线节点（见下）

### 界面

显示受控面板数、平均缓冲、当前输出档位、已断开的总线数量。

### 配置

```toml
[fluxGovernor]
radius = 8
intervalTicks = 20
highBuffer = 0.95
lowBuffer = 0.8
```

## 四、优先级总线节点

### 作用

带缓冲的 FE 中转站。电量紧张时被调控器按优先级切断，保住关键负载。

> **接线方式（重要）**
> 总线节点必须**串联**在供能与负载之间：电从一侧进入节点，再由另一侧送往机器。
> 它**不能像储电箱那样并联在电网上**——并联时机器直接从主网取电，切断节点起不到任何作用。
> 节点本身**没有方向限制**（任意一面都能收发），"进口/出口"取决于你怎么接线，而不是方块朝向。
> 同时，节点必须位于**通量调控器的扫描半径内**才会被接管；超出半径的节点只是一个普通缓冲方块。

| 属性 | 数值 |
|---|---|
| 缓冲 | 200,000 FE |
| 吞吐 | 20,000 FE/t |
| 优先级 | 1（最低）~ 5（最高） |

### 三种状态

- **供能中**：正常收发
- **已降载**：被调控器断开，既不接收也不输出
- **已强制断开**：玩家手动关闭

### 调度规则

调控器扫描范围内所有总线节点，统计总缓冲比例：

```
< 20%  → 每轮断开一条最低优先级的节点
> 40%  → 每轮恢复一条最高优先级的节点
```

### 界面

`−` / `+` 调整优先级，底部按钮切换强制通断，缓冲条显示当前电量。

```toml
[priorityBus]
lowNetwork = 0.2
highNetwork = 0.4
```

## 六、亚空间中继信标

### 作用

随身充能器：把附近太阳能板的电抽入自身缓冲，再给背包里的能量物品充电。

> **接线方式**
> 信标**不需要接线**，也不参与电网。
> 它是随身设备——放在背包或饰品栏即可，直接从范围内面板的缓冲抽取，绕过所有线缆和储电方块。

### 两种工作模式

| 模式 | 条件 | 抽取范围 |
|---|---|---|
| 本地 | 未装备耦合卡 | 半径 16 格内的耀阳板 |
| 跨维度 | 耦合卡**装备在饰品栏** | 卡片绑定的那一台面板，可跨维度 |

### 充能循环（每 20 tick）

1. 从面板抽 FE 进入信标缓冲（上限 400,000 FE）
2. 扣除维护费，不足则停止
3. 将缓冲充给物品，**效率 90%**（10% 为传输损耗，不凭空生成）

充能顺序：**主手 → 副手 → 护甲 → 其余背包**。

### 双生效路径

- 放在背包/快捷栏：由玩家 tick 驱动
- 装备在 Curios 饰品栏：由 `curioTick` 驱动
- 两者同时存在时**优先饰品栏**，不会重复扣电
- 未安装 Curios 时自动退化为纯背包模式

### 配置

```toml
[subspaceRelay]
radius = 16
capacity = 400000
transferPerTick = 2000
efficiency = 0.9
upkeepPerCycle = 10
```

## 七、超立方耦合卡

### 作用

把某台耀阳板登记为信标的专属电源，突破 16 格限制并允许跨维度。

### 操作

| 操作 | 结果 |
|---|---|
| **Shift + 右键**耀阳板 | 绑定（记录维度、坐标、所有者） |
| **Shift + 右键**同一块板 | 解绑 |
| 普通右键面板 | 打开面板界面（不绑定） |

### 生效条件

1. 卡片必须**装备在饰品栏**（护符 / 背饰槽），放在背包不生效
2. 目标区块已加载
3. 目标面板有电
4. 信标缓冲未满

### 失效情况

- 源面板被拆除 → 抽取为 0，信标退回本地模式
- 源区块未加载 → 不抽电（不会强制加载）

## 八、超立方锚定节点

### 作用

强制加载所在区块并保持运转，让远端面板继续发电。

> **放置位置**
> 锚点加载的是**它自己所在的区块**，不会连带加载周围区块。
> 必须把它放在面板所在的同一个区块内（按 F3+G 可显示区块边界），否则面板照常停止。
> 一个区块放一个锚点即可覆盖该区块的全部方块。

- 放置即加载所在区块（ticking）
- 拆除即释放
- 每个维度最多 **3 个**（可配置），超限无法放置

```toml
[tesseractAnchor]
maxChunks = 3
```

## 十、典型玩法

### 中期：本地充能

1. 铺设太阳能板，接入储电方块
2. 携带中继信标在附近活动
3. 背包内的电池与工具自动回电

### 后期：跨维度供电

1. 主世界建好太阳能阵列
2. 阵列旁放置锚定节点保证区块加载
3. 手持耦合卡 Shift + 右键绑定面板
4. 将耦合卡装备到饰品栏
5. 携带信标前往末地，物品开始回电

### 满电管理

1. 阵列中央放置通量调控器
2. 关键产线接优先级 5 的总线节点，次要设备接 1–2
3. 电量不足时低优先级节点被优先断开

## 十一、常见问题

**Q：面板不发电？**
检查上方是否被方块遮挡、是否在下雨、是否处于无天空光的维度。

**Q：信标不充电？**
确认缓冲未满、维护费扣得起、附近有已加载的耀阳板；跨维度模式还需卡片装备在饰品栏且源区块已加载。

**Q：耦合卡装不进饰品栏？**
需要安装 Curios，卡片已加入 `curios:charm` 与 `curios:back` 标签。

**Q：调控器把输出压到 0 后如何恢复？**
缓冲降到 80% 以下会自动逐级恢复，也可临时拆除调控器。

**Q：AE2 里看不到电？**
需要 Energy Acceptor 将 FE 转为 AE，比例 2:1。

**Q：能看到工作范围吗？**
手持调控器或总线节点时会显示线框；可在「模组列表 → Sunflare Solar → Config」中关闭 `rangePreview`。

## 十二、兼容与限制

- **能量接口**：仅使用 NeoForge `IEnergyStorage`，不依赖任何第三方能量模组
- **可选依赖**：Curios（未安装时自动降级）
- **不跨维度供电**：不对未加载区块做任何逻辑
- **不主动加载区块**：只有锚定节点会强制加载，且数量受限
- **单区块扫描**：调控器只处理已加载区块内的方块
